### 注解索引体系设计

#### 1. 按功能模块分类

| 模块    | 注解数量 | 示例                                                 |
| ----- | ---- | -------------------------------------------------- |
| IoC容器 | 15+  | @Component, @Service, @Repository, @Configuration  |
| 依赖注入  | 8+   | @Autowired, @Qualifier, @Primary, @Value           |
| 配置管理  | 10+  | @ConfigurationProperties, @Profile, @Conditional\* |
| AOP   | 6+   | @Aspect, @Pointcut, @Before, @After, @Around       |
| Web开发 | 20+  | @RestController, @RequestMapping, @PathVariable    |
| 数据访问  | 12+  | @Transactional, @Entity, @Repository, @Modifying   |
| 安全    | 10+  | @Secured, @PreAuthorize, @RolesAllowed             |
| 测试    | 8+   | @SpringBootTest, @MockBean, @DataJpaTest           |

#### 2. 注解详情模板

```markdown
## @Transactional

### 基本信息
- **所属模块**: 数据访问/事务管理
- **作用范围**: 类/方法
- **Spring版本**: 1.0+

### 核心属性
| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| propagation | Propagation | REQUIRED | 传播行为 |
| isolation | Isolation | DEFAULT | 隔离级别 |
| timeout | int | -1 | 超时时间(秒) |
| readOnly | boolean | false | 是否只读 |
| rollbackFor | Class[] | {} | 回滚异常类型 |

### 应用场景
- 场景1: 服务层方法事务控制
- 场景2: 批量操作事务管理
- 场景3: 只读查询优化

### 使用示例
[代码示例]

### 注意事项
- ⚠️ 只能应用于public方法
- ⚠️ 同类调用不生效（代理机制）
- ⚠️ 异常类型选择

### 相关注解
@EnableTransactionManagement, @TransactionalEventListener

### 常见问题
- Q: 为什么事务不生效？
- Q: 如何处理嵌套事务？
```
