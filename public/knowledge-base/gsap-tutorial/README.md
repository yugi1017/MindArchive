# GSAP 动画教程

> 从零开始掌握GSAP动画技术，打造流畅、专业的网页动画效果

## 教程简介

GSAP（GreenSock Animation Platform）是业界最强大的JavaScript动画库，被超过1100万个网站使用，包括Apple、Google、Netflix等顶级公司。本教程采用由浅入深的系统化教学结构，帮助你从基础到进阶全面掌握GSAP动画技术。

### 为什么学习GSAP？

| 特性 | 说明 |
|------|------|
| **极致性能** | 比CSS动画和jQuery动画快20倍以上 |
| **跨浏览器兼容** | 完美支持所有现代浏览器，自动处理兼容性问题 |
| **丰富功能** | 时间线控制、缓动函数、滚动触发、SVG动画等 |
| **易于学习** | API设计直观，学习曲线平缓 |
| **活跃社区** | 完善的文档和活跃的社区支持 |

### 适用人群

- 前端开发工程师
- UI/UX设计师
- 网页动画爱好者
- 想要提升网站交互体验的开发者

## 学习建议

### 循序渐进

1. **不要跳章**：每章内容环环相扣，基础扎实才能学好进阶
2. **动手实践**：每学一个概念都要亲自编写代码验证
3. **举一反三**：尝试修改示例参数，观察效果变化

### 学习方法

```
阅读理论 → 运行示例 → 修改参数 → 创建变体 → 应用项目
```
