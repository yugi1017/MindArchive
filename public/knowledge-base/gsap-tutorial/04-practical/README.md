## 快速预览

所有案例都提供完整的HTML、CSS和JavaScript代码，可以直接复制使用。

### 使用方法

1. 复制案例代码
2. 确保已引入GSAP库
3. 根据需要调整参数

### 基础模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>GSAP动画示例</title>
  <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
  <style>
    /* 在这里添加CSS */
  </style>
</head>
<body>
  <!-- 在这里添加HTML -->
  
  <script>
    // 在这里添加JavaScript
  </script>
</body>
</html>
```
