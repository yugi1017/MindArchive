# 第1章 GSAP是什么

> 理解GSAP的定位、核心价值与应用场景

## 1.1 GSAP简介

### 什么是GSAP？

GSAP（GreenSock Animation Platform）是一个高性能的JavaScript动画库，由GreenSock公司开发维护。它让创建复杂的网页动画变得简单而高效。

```text
┌─────────────────────────────────────────────────────────────┐
│                         GSAP 架构                            │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────────┐    │
│  │  Core   │  │ Timeline│  │  Easing │  │   Plugins   │    │
│  │  核心库  │  │  时间线  │  │  缓动   │  │   插件系统   │    │
│  └────┬────┘  └────┬────┘  └────┬────┘  └──────┬──────┘    │
│       │            │            │              │            │
│       └────────────┴────────────┴──────────────┘            │
│                           │                                  │
│                    ┌──────┴──────┐                          │
│                    │   动画引擎   │                          │
│                    └─────────────┘                          │
└─────────────────────────────────────────────────────────────┘
```

### 核心组成部分

| 组件 | 说明 |
|------|------|
| **Core（核心）** | 基础动画功能，gsap.to()、gsap.from()等方法 |
| **Timeline（时间线）** | 动画序列管理，精确控制多个动画的时序 |
| **Easing（缓动）** | 丰富的缓动函数，让动画更自然流畅 |
| **Plugins（插件）** | 扩展功能，如ScrollTrigger、Draggable等 |

## 1.2 为什么选择GSAP？

### 性能对比

GSAP在动画性能方面远超其他方案：

```text
性能对比（数值越高越好）
│
│  ████████████████████████████████████████  GSAP (100%)
│  █████████████████████  CSS动画 (60%)
│  ████████████  jQuery动画 (30%)
│
└──────────────────────────────────────────────
```

### 核心优势

#### 1. 极致性能

GSAP使用优化的JavaScript引擎，比CSS动画和jQuery动画快20倍以上：

- 智能缓存机制
- 优化的渲染循环
- 自动使用GPU加速

#### 2. 跨浏览器兼容

GSAP自动处理浏览器差异：

```javascript
// GSAP自动处理各浏览器的transform前缀
gsap.to(".box", {
  transform: "rotate(45deg)",  // 自动添加-webkit-等前缀
  duration: 1
});
```

#### 3. 精确控制

提供完整的动画控制能力：

```javascript
const tween = gsap.to(".box", { x: 100, duration: 2 });

tween.pause();      // 暂停
tween.play();       // 播放
tween.reverse();    // 反向播放
tween.restart();    // 重新开始
tween.seek(0.5);    // 跳转到指定时间点
tween.timeScale(2); // 改变播放速度
```

#### 4. 丰富功能

| 功能 | 说明 |
|------|------|
| 时间线 | 管理复杂的动画序列 |
| 缓动函数 | 40+种内置缓动效果 |
| 交错动画 | 批量元素的延迟动画 |
| 回调函数 | 完整的动画生命周期事件 |
| 插件系统 | ScrollTrigger、Draggable、MorphSVG等 |

## 1.3 GSAP vs CSS动画

### 功能对比

| 特性 | GSAP | CSS动画 |
|------|------|---------|
| 浏览器兼容 | 完美兼容 | 部分兼容 |
| 动画控制 | 完全可控 | 有限控制 |
| 时间线 | 强大支持 | 无原生支持 |
| 缓动函数 | 40+种 | 有限选择 |
| SVG动画 | 完美支持 | 有限支持 |
| 滚动动画 | ScrollTrigger插件 | 需要额外代码 |
| 学习曲线 | 中等 | 简单 |

### 使用场景选择

**选择GSAP的场景：**
- 复杂的动画序列
- 需要精确控制动画进度
- 滚动触发动画
- SVG路径动画
- 需要兼容旧浏览器

**选择CSS动画的场景：**
- 简单的过渡效果
- hover状态变化
- 性能敏感的移动端
- 不需要JavaScript的简单动画

## 1.5 GSAP版本演进

### 版本历史

| 版本 | 发布时间 | 主要特性 |
|------|----------|----------|
| GSAP 1.x | 2012年 | 基础动画功能 |
| GSAP 2.x | 2017年 | 性能优化、新插件 |
| GSAP 3.x | 2019年 | 统一API、更小体积、TypeScript支持 |

### GSAP 3.x 重大改进

```javascript
// GSAP 2.x 写法
TweenMax.to(".box", 1, { x: 100, ease: Power2.easeOut });

// GSAP 3.x 写法（更简洁）
gsap.to(".box", { x: 100, duration: 1, ease: "power2.out" });
```

主要改进：
- 统一的`gsap`全局对象
- 更简洁的API语法
- 体积减少约50%
- 原生TypeScript支持
- 新的缓动函数命名
