# 项目说明

## 个人学习知识库系统

一个轻量级的学习资料管理系统，无需后台和数据库，纯前端实现。

## 技术架构特性

### 纯前端实现

本项目采用 **纯前端架构**，具有以下核心优势：

#### 零后端依赖
- 无需服务器配置
- 无需数据库设计
- 无需 API 接口开发
- 无需后端运维知识

#### 零运维成本
- 可直接部署于 GitHub Pages、Vercel、Netlify 等静态托管平台
- 无需服务器监控、扩容、备份
- 无需处理服务器安全更新

#### 高性能体验
- 所有数据本地加载，无网络延迟
- 静态资源可充分利用 CDN 加速
- 无数据库查询瓶颈

#### 高可移植性
- 可离线运行
- 可打包为桌面应用
- 可部署到任意静态托管平台

### 数据存储方案

#### 前端直接存储的优势

相比传统数据库方案，前端直接存储知识库数据更适合 AI 维护：

| 特性 | 传统数据库 | 前端存储 |
|-----|-----------|---------|
| 结构灵活性 | 需要预定义表结构 | JSON 格式，灵活可变 |
| 版本控制 | 需要额外方案 | 天然 Git 友好 |
| 迁移成本 | 版本升级复杂 | 无迁移问题 |
| 审查难度 | 需要数据库工具 | 直接查看文件 |
| AI 友好度 | 需要 SQL 知识 | 直接编辑文件 |

#### 实时更新机制

```
用户修改 → 文件更新 → Git 提交 → 自动部署 → 用户刷新 → 即时生效
```

无需处理：
- 数据库缓存同步
- Redis 缓存失效
- CDN 缓存刷新
- 消息队列通知

## 知识库内容管理

### AI 原生内容生成

所有知识库内容均由 AI 生成并维护：

#### 内容创建
- AI 根据主题自动生成结构化学习内容
- 自动划分章节、设置学习目标
- 自动生成代码示例和说明

#### 内容更新
- 通过自然语言指令即可完成内容修改
- AI 理解上下文，保持内容一致性
- 批量更新多个相关文档

#### 结构优化
- AI 自动分析知识库组织结构
- 智能推荐内容重组方案
- 自动生成索引和导航

### 维护操作指南

#### 添加新知识库

1. 创建知识库目录
2. 添加 Markdown 文档
3. 更新 `src/data/index.json` 配置

#### 更新文档内容

直接编辑 Markdown 文件，AI 可辅助：
- 内容扩展
- 格式优化
- 错误修正

#### 调整知识库结构

修改 `src/data/index.json` 中的配置：
- 章节顺序调整
- 文档分类变更
- 标签管理

## 配置字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 唯一标识符 |
| title | 是 | 知识库/文档标题 |
| icon | 否 | 图标（emoji） |
| description | 否 | 描述信息 |
| path | 是 | Markdown 文件路径（相对路径） |
| tags | 否 | 标签数组，用于搜索 |
| learningObjectives | 否 | 学习目标数组 |
