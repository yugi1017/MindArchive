# 第19章 Prompt工程进阶

> 从基础到进阶的Prompt技巧，让AI更懂你的需求

## 什么是Prompt工程？

### 定义

> Prompt工程是设计和优化输入给AI的指令，以获得更好输出的技术。

### 为什么重要？

| 原因 | 说明 |
|------|------|
| 影响输出质量 | 好的Prompt = 好的输出 |
| 提高效率 | 减少来回沟通 |
| 解锁能力 | 让AI发挥更大潜力 |

## Prompt基础回顾

### 基本公式

```
背景 + 任务 + 要求 = 好结果
```

### 基础示例

**差的Prompt**：
```
帮我写个东西
```

**好的Prompt**：
```
背景：我是产品经理，需要向老板汇报项目进度
任务：帮我写一份项目进度汇报邮件
要求：
1. 包含本周完成的工作、遇到的问题、下周计划
2. 语气正式但不生硬
3. 300字左右
```

## 进阶技巧

### 技巧一：角色设定

**用法**：让AI扮演特定角色

**格式**：
```
你是一个[角色]，具有[特点]。
[任务描述]
```

**示例**：
```
你是一个资深产品经理，有10年互联网产品经验。
请帮我评审这份PRD，指出问题和改进建议：
[PRD内容]
```

**常用角色**：
| 角色 | 适用场景 |
|------|----------|
| 资深程序员 | 代码审查、技术方案 |
| 产品经理 | 需求分析、产品设计 |
| 文案专家 | 文案撰写、内容优化 |
| 数据分析师 | 数据分析、报告生成 |
| 面试官 | 模拟面试、问题设计 |

### 技巧二：Few-shot学习

**用法**：给AI几个示例，让它学习模式

**格式**：
```
请按照以下示例格式输出：

示例1：
输入：[输入1]
输出：[输出1]

示例2：
输入：[输入2]
输出：[输出2]

现在请处理：
输入：[你的输入]
```

**示例**：
```
请按照以下格式生成产品描述：

示例1：
输入：iPhone 15
输出：iPhone 15，苹果最新旗舰手机，搭载A17芯片，钛金属边框，4800万像素主摄，为你带来极致体验。

示例2：
输入：小米14
输出：小米14，小米年度旗舰，骁龙8 Gen3处理器，徕卡影像系统，1.5K直屏，性价比之选。

现在请生成：
输入：华为Mate 60
```

### 技巧三：思维链（Chain of Thought）

**用法**：让AI展示思考过程

**格式**：
```
请一步步思考：
[任务描述]
```

**示例**：
```
问题：小明有5个苹果，给了小红2个，又买了3个，现在有几个？

请一步步思考：
```

**AI输出**：
```
让我一步步分析：

1. 小明最初有5个苹果
2. 给了小红2个，剩下：5 - 2 = 3个
3. 又买了3个，现在有：3 + 3 = 6个

答案：小明现在有6个苹果。
```

### 技巧四：结构化输出

**用法**：指定输出格式

**格式**：
```
请以[格式]输出：
[任务描述]

输出格式：
[格式示例]
```

**示例**：
```
请分析以下产品的优劣势：

产品：iPhone 15

输出格式：
## 优势
- [优势1]
- [优势2]

## 劣势
- [劣势1]
- [劣势2]

## 总结
[总结内容]
```

### 技巧五：约束条件

**用法**：明确限制条件

**格式**：
```
[任务描述]

约束条件：
- [约束1]
- [约束2]
- [约束3]
```

**示例**：
```
请写一篇关于AI的文章

约束条件：
- 字数：500字左右
- 风格：通俗易懂
- 受众：非技术人员
- 不使用专业术语
- 包含3个生活化例子
```

### 技巧六：迭代优化

**用法**：通过多轮对话优化结果

**流程**：
```
第1轮：生成初稿
第2轮：提出修改意见
第3轮：优化完善
...
```

**示例**：
```
第1轮：
请写一份产品介绍

第2轮：
这个介绍太长了，请精简到200字以内

第3轮：
请增加一些情感化的表达

第4轮：
请在开头加一句吸引人的标题
```

### 技巧七：分解复杂任务

**用法**：把复杂任务拆分成多个简单任务

**格式**：
```
任务：[复杂任务]

请分步骤完成：
步骤1：[子任务1]
步骤2：[子任务2]
步骤3：[子任务3]
```

**示例**：
```
任务：帮我策划一个线上活动

请分步骤完成：
步骤1：分析活动目标和受众
步骤2：设计活动形式和规则
步骤3：制定推广方案
步骤4：设计数据追踪方案
```

### 技巧八：自我反思

**用法**：让AI自我检查和改进

**格式**：
```
[任务描述]

完成后，请自我检查：
1. 是否满足所有要求？
2. 是否有遗漏或错误？
3. 如何改进？
```

**示例**：
```
请写一份产品需求文档

完成后，请自我检查：
1. 需求描述是否清晰？
2. 是否考虑了边界情况？
3. 验收标准是否明确？
如有问题，请修改后重新输出。
```

## 高级应用

### 多角色对话

**用法**：让AI模拟多个角色对话

**示例**：
```
请模拟一场产品评审会议：
角色：产品经理、技术负责人、设计师
讨论议题：用户登录功能的设计方案
```

### 知识注入

**用法**：给AI提供背景知识

**示例**：
```
背景知识：
[相关知识]

基于以上知识，请回答：
[问题]
```

### 输出验证

**用法**：让AI验证输出的正确性

**示例**：
```
请生成一段代码，并验证：
1. 语法是否正确
2. 逻辑是否完整
3. 是否有潜在问题
```

## Prompt模板库

### 写作类

**文章写作**：
```
主题：[主题]
目标读者：[读者]
风格：[风格]
字数：[字数]
请写一篇文章，包含：
1. 引言
2. 正文（3-5个要点）
3. 结论
```

**邮件写作**：
```
收件人：[收件人]
目的：[目的]
要点：[要点]
语气：[语气]
请写一封邮件
```

### 分析类

**竞品分析**：
```
产品A：[描述]
产品B：[描述]
请从以下维度对比：
1. 产品定位
2. 核心功能
3. 目标用户
4. 商业模式
5. 优劣势
```

**数据分析**：
```
数据：[数据描述]
请分析：
1. 数据趋势
2. 异常点
3. 可能原因
4. 建议措施
```

### 编程类

**代码生成**：
```
功能：[功能描述]
技术栈：[技术栈]
要求：
- [要求1]
- [要求2]
请生成代码并添加注释
```

**代码审查**：
```
代码：[代码]
请审查：
1. 代码质量
2. 潜在问题
3. 优化建议
```

## 常见问题

### Q：为什么AI的回答不符合预期？

A：可能原因：
- Prompt不够清晰
- 缺少上下文
- 要求太模糊
- 任务太复杂

### Q：如何提高Prompt质量？

A：方法：
- 明确具体要求
- 提供足够上下文
- 使用结构化格式
- 分解复杂任务

### Q：不同AI工具的Prompt有区别吗？

A：有区别：
- 不同模型理解能力不同
- 需要根据模型调整
- 多尝试找到最佳方式
