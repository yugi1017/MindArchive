### Midjourney

**定位**：专业级AI图像生成

**特点**：
- 🎨 图像质量最高
- 🎭 风格多样
- 📐 支持多种比例
- 🔧 参数丰富

**使用方式**：
- 通过Discord使用
- 输入`/imagine`命令 + 描述

**Prompt技巧**：
```
/imagine a cute cat sitting on a windowsill, 
soft sunlight, photorealistic, 4k --ar 16:9
```

**常用参数**：
| 参数 | 作用 |
|------|------|
| --ar | 设置比例 |
| --v | 版本号 |
| --style | 风格 |
| --q | 质量 |

## AI设计最佳实践

### 1. 写好Prompt

**图像生成Prompt公式**：
```
主体 + 风格 + 环境 + 光线 + 视角 + 质量
```

**例子**：
```
一只可爱的猫咪（主体）
坐在窗台上（环境）
阳光柔和（光线）
照片级真实感（风格）
4K高清（质量）
```

### 2. 迭代优化

- 第一次生成不满意？调整描述
- 多尝试不同风格
- 结合多个工具使用

### 3. 保持原创性

- AI生成是起点，不是终点
- 加入个人创意
- 注意版权问题

## 常见问题

### Q：AI生成的图片有版权吗？

A：情况复杂：
- 不同平台政策不同
- 商用需仔细阅读条款
- 建议作为灵感来源，再创作

### Q：AI会取代设计师吗？

A：不会，但会改变工作方式：
- 从"执行"变成"指导"
- 效率大幅提升
- 创意更重要

### Q：如何提高生成质量？

A：技巧：
- 描述越具体越好
- 参考优秀Prompt
- 多次迭代优化
