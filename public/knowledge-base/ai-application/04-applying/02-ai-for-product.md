## 一、需求分析

### 需求梳理实战

**场景**：收到一个模糊的需求，需要快速梳理清楚

**操作步骤**：

**第一步：输入原始需求**
```
我收到一个需求：用户需要一个搜索功能
产品背景：电商App，用户反馈找不到商品

请帮我：
1. 梳理需求要点
2. 发现可能的遗漏
3. 提出需要确认的问题
4. 给出功能范围建议
```

**AI输出示例**：
```
## 需求要点
1. 搜索入口位置：首页顶部？底部导航？
2. 搜索范围：商品名称？描述？分类？
3. 搜索结果：列表展示？网格展示？
4. 筛选条件：价格、品牌、销量等？

## 可能遗漏
1. 搜索历史记录
2. 热门搜索推荐
3. 搜索无结果时的处理
4. 语音搜索功能
5. 图片搜索功能

## 需要确认
1. 搜索响应时间要求？
2. 是否需要模糊匹配？
3. 是否需要搜索联想？
4. 搜索结果排序规则？

## 功能范围建议
MVP版本：
- 基础关键词搜索
- 搜索历史
- 热门搜索

迭代版本：
- 高级筛选
- 语音搜索
- 图片搜索
```

**第二步：深入挖掘**
```
基于以上分析，请帮我：
1. 画出功能架构图（用文字描述）
2. 列出核心功能点
3. 评估开发工作量
```

### 需求优先级分析

**场景**：需求太多，不知道先做哪个

**操作步骤**：
```
我有以下需求列表：
1. 用户搜索功能
2. 商品收藏功能
3. 订单评价功能
4. 优惠券功能
5. 分享功能

产品背景：电商App，日活10万，转化率低

请帮我：
1. 按价值-成本矩阵分析优先级
2. 给出推荐的开发顺序
3. 说明理由
```

**AI输出示例**：
```
## 优先级分析

| 需求 | 用户价值 | 开发成本 | 优先级 | 理由 |
|------|----------|----------|--------|------|
| 搜索功能 | 高 | 中 | P0 | 直接影响转化率 |
| 优惠券功能 | 高 | 低 | P0 | 快速提升转化 |
| 收藏功能 | 中 | 低 | P1 | 提升复购 |
| 评价功能 | 中 | 中 | P2 | 社交证明 |
| 分享功能 | 低 | 低 | P3 | 增长辅助 |

## 推荐开发顺序
第一期：搜索功能 + 优惠券功能
第二期：收藏功能
第三期：评价功能 + 分享功能

## 理由
当前核心问题是转化率低，搜索和优惠券直接解决此问题，
建议优先开发，预计可提升转化率15-20%。
```

## 二、竞品调研

### 快速竞品分析

**场景**：需要快速了解竞品情况

**操作步骤**：
```
请帮我分析以下竞品：
产品A：淘宝
产品B：京东
产品C：拼多多

分析维度：
1. 产品定位和目标用户
2. 核心功能对比
3. 商业模式差异
4. 用户体验亮点
5. 我们可以学习的点

输出格式：对比表格 + 分析结论
```

### 功能对比分析

**场景**：需要对比某个具体功能

**操作步骤**：
```
请对比以下App的搜索功能：
- 淘宝
- 京东
- 拼多多

对比维度：
1. 搜索入口位置
2. 搜索联想方式
3. 筛选条件
4. 结果展示形式
5. 特色功能

请用表格形式输出，并给出最佳实践建议
```

## 三、PRD撰写

### 完整PRD生成

**场景**：需要快速生成PRD文档

**操作步骤**：

**第一步：生成PRD框架**
```
请帮我生成一份PRD文档框架：
功能名称：用户搜索功能
产品背景：电商App
目标用户：购物用户

包含以下章节：
1. 需求背景
2. 需求目标
3. 用户故事
4. 功能详情
5. 非功能需求
6. 验收标准
```

**第二步：填充具体内容**
```
基于以上框架，请帮我填充"功能详情"部分：
- 搜索入口：首页顶部搜索框
- 搜索范围：商品名称、描述
- 搜索历史：保留最近10条
- 热门搜索：运营配置

请详细描述每个功能的：
1. 页面布局
2. 交互逻辑
3. 异常处理
4. 边界条件
```

**完整PRD示例**：
```markdown
# 用户搜索功能PRD

## 1. 需求背景
用户反馈在App中难以找到想要的商品，导致流失率高。
数据显示，70%的用户在浏览3页后仍未找到目标商品。

## 2. 需求目标
- 提升商品找到率：从30%提升到60%
- 降低用户流失率：从45%降低到25%
- 提升转化率：从2%提升到3%

## 3. 用户故事
| 角色 | 需求 | 价值 |
|------|------|------|
| 购物用户 | 快速找到想要的商品 | 节省时间 |
| 购物用户 | 看到相关推荐 | 发现更多选择 |
| 运营人员 | 配置热门搜索 | 引导用户关注 |

## 4. 功能详情

### 4.1 搜索入口
**位置**：首页顶部
**样式**：圆角搜索框 + 搜索图标 + 占位文字"搜索商品"
**交互**：
- 点击跳转搜索页
- 支持语音输入（可选）

### 4.2 搜索页面
**布局**：
- 顶部：搜索框 + 取消按钮
- 中间：搜索历史 + 热门搜索
- 底部：搜索结果列表

**搜索历史**：
- 保留最近10条
- 支持单条删除
- 支持清空全部

**热门搜索**：
- 运营后台配置
- 最多展示10个
- 按权重排序

### 4.3 搜索结果
**展示形式**：双列网格
**排序规则**：综合排序（销量+评价+价格）
**筛选条件**：价格区间、品牌、销量

## 5. 非功能需求
- 搜索响应时间：<500ms
- 支持并发：1000 QPS
- 搜索准确率：>90%

## 6. 验收标准
- [ ] 用户可以输入关键词搜索
- [ ] 搜索结果正确展示
- [ ] 搜索历史正确记录
- [ ] 热门搜索正确展示
- [ ] 筛选功能正常
```

## 四、用户洞察

### 用户画像生成

**场景**：需要了解目标用户

**操作步骤**：
```
产品：健身App
功能：运动记录、课程跟练、社区分享

请帮我生成用户画像：
1. 核心用户群体（3-5个）
2. 每个群体的：
   - 基本信息（年龄、职业、收入）
   - 行为特征
   - 需求痛点
   - 使用场景
```

### 用户反馈分析

**场景**：收集了大量用户反馈，需要分析

**操作步骤**：
```
以下是用户反馈：
[粘贴反馈内容]

请帮我：
1. 分类整理（功能问题、体验问题、建议）
2. 提取高频问题
3. 分析问题优先级
4. 给出改进建议
```

### 数据报告生成

**场景**：需要分析产品数据

**操作步骤**：
```
以下是本周产品数据：

- 新增用户：2万
- 留存率：次日40%，7日20%

- 人均时长：8分钟

请帮我：
1. 分析数据变化原因
2. 指出需要关注的问题
3. 给出优化建议
```
