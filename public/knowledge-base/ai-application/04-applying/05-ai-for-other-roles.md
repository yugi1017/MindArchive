## 一、编辑工作

### 编辑的AI工作流

```
选题策划 → 资料收集 → 内容创作 → 编辑优化 → 审核发布
    ↓          ↓          ↓          ↓          ↓
 AI热点     AI整理     AI辅助     AI校对    AI检查
```

### 1. 选题策划阶段

**传统方式**：人工浏览各平台热点，耗时2-3小时

**AI方式**：5分钟完成选题分析

**实操步骤**：

**第一步：热点收集**
```
请帮我分析今天[行业/领域]的热点话题：
时间范围：最近24小时
分析维度：
1. 热点事件列表（5-10个）
2. 每个热点的热度指数
3. 每个热点的讨论角度
4. 推荐的选题方向

输出格式：
## 热点概览
| 热点事件 | 热度指数 | 主要讨论 | 推荐指数 |
|---------|---------|---------|---------|
| ... | ... | ... | ... |

## 推荐选题
1. [选题1]：[推荐理由]
2. [选题2]：[推荐理由]
```

**第二步：选题评估**
```
我选择了这个选题：[选题描述]
请帮我评估：
1. 目标读者是谁？
2. 他们关心什么？
3. 竞品文章有哪些角度？
4. 我们可以有什么差异化角度？
5. 预估阅读量区间
```

**真实案例**：
> 某科技媒体编辑，原来每天花2小时找选题，现在用AI分析热点，5分钟确定选题，效率提升96%。

**完整创作流程**：

```

```

```

```

2. 每条规则的判断标准

### 5. 进阶：什么时候考虑智能体平台？

**大多数情况下，直接用对话式AI（豆包、Kimi、DeepSeek）就够了。**

**以下场景可以考虑智能体平台**：
- 每天批量处理同类任务（如批量审核、批量文案生成）
- 团队多人共用同一套规则
- 需要对接多个工具或数据源

**推荐的智能体平台**：

| 平台 | 特点 | 推荐理由 |
|------|------|----------|
| 扣子(Coze) | 零代码，模板丰富，国内可用 | 非技术人员快速搭建 |
| Dify云版 | 工作流强大 | 需要复杂流程 |

## 七、常见问题与解决方案

### Q1：AI生成的内容太泛，不够具体怎么办？

**解决方案**：
```
请针对[具体场景]，给出[具体数量]个具体例子。
每个例子要包含：[具体要素]
```

### Q2：AI生成的内容风格不对怎么办？

**解决方案**：
```
请参考以下示例的风格：
[示例内容]

请用同样的风格，写[新内容]
```

### Q3：如何保护公司机密？

**解决方案**：
1. 脱敏处理：替换敏感信息为占位符
2. 使用企业版工具：数据不用于训练
3. 本地部署：使用开源模型

### Q4：AI生成的内容有错误怎么办？

**解决方案**：
1. 交叉验证：用多个来源核实
2. 专业审核：关键内容请专家审核
3. 迭代修正：指出错误让AI修正
