# AI 应用知识库

> 从零开始认识AI，循序渐进理解AI，将AI应用到工作中

## 知识库定位

本知识库的目标不是让你成为AI专家，而是帮助你：

- **接触AI**：打破对AI的陌生感和恐惧感
- **理解AI**：将专业名词从生词变成可以理解的词
- **使用AI**：掌握AI工具，让AI成为你的助手
- **运用AI**：将AI应用到实际工作中，提升效率

## 2026年AI核心趋势

根据最新资讯，2026年AI领域有以下重要变化：

### 1. 从"生成"到"代理"
- AI发展的关键词从"生成"转向"代理"
- AI不再只是生成内容，而是能理解目标、分解任务、调用工具并交付结果
- Agent智能体成为新主线

### 2. 物理AI的崛起
- AI从虚拟智能进化为实体智能
- 具身智能机器人迎来"ChatGPT时刻"
- AI能理解物理世界的规律

### 3. 技术奇点提前
- 马斯克称2026年是"奇点之年"
- Claude Code等工具引发编码革命
- AI编程能力实现质变

### 4. 国内大模型竞争格局
- 豆包月活领先，DeepSeek紧随其后
- 智谱AI、MiniMax等企业加速上市
- 竞争核心从参数比拼转向场景落地
