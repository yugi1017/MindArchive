## 豆包快速上手

### 1. 注册登录

**网页版**：
1. 打开网址：https://www.doubao.com
2. 使用手机号或抖音账号登录

**手机App**：
1. 应用商店搜索"豆包"
2. 下载安装
3. 使用手机号登录

### 2. 第一次对话

登录后，你会看到一个对话框。试着输入：

```
你好，请介绍一下你自己
```

豆包会回复它的功能和能力。

### 3. 常用功能

| 功能 | 怎么用 | 示例 |
|------|--------|------|
| 问答 | 直接输入问题 | "什么是人工智能？" |
| 写作 | 告诉它你要写什么 | "帮我写一封请假邮件" |
| 翻译 | 输入要翻译的内容 | "把这段话翻译成英文：..." |
| 总结 | 粘贴长文本 | "帮我总结这篇文章的要点" |
| 画图 | 描述你想要的图片 | "画一只可爱的猫咪" |

### 4. 实用示例

**写工作邮件**：
```
帮我写一封给老板的邮件，说明项目进度延迟的原因，并提出解决方案。
延迟原因：技术难题需要额外时间
解决方案：增加人手、调整排期
```

**学习新知识**：
```
请用简单的话解释什么是"区块链"，并举一个生活中的例子。
```

**制定计划**：
```
帮我制定一个学习Python的计划，我是完全的编程新手，每天有1小时学习时间。
```

### Kimi的独特优势

- 📄 能读取超长文档（最多20万字）

- 🔍 能联网搜索最新信息

**网页版**：https://kimi.moonshot.cn

1. 点击上传文件按钮

3. 让Kimi帮你总结、分析

**示例**：
```
上传一份产品需求文档，然后问：
"请总结这份文档的核心需求，并列出关键功能点"
```

**长文阅读**：
```
粘贴一篇长文章，然后问：
"这篇文章的主要观点是什么？有哪些论据支持？"
```

## 提问技巧

### 好问题 vs 差问题

| 差问题 | 好问题 |
|--------|--------|
| "帮我写点东西" | "帮我写一封求职邮件，应聘产品经理岗位，强调我的数据分析能力" |
| "这个怎么做" | "我想用Excel做数据透视表，请告诉我具体步骤" |
| "介绍一下AI" | "请用通俗的语言介绍AI，并举3个生活中的应用例子" |

### 提问公式

**背景 + 任务 + 要求 = 好结果**

示例：
```
背景：我是一个产品经理新人
任务：需要写一份竞品分析报告
要求：分析抖音和快手的产品定位差异，格式清晰，500字左右
```

### 常用提问模板

**写作类**：
```
请帮我写一篇[类型]，主题是[主题]，风格是[风格]，字数约[字数]。
```

**学习类**：
```
请用简单的话解释[概念]，并举一个生活中的例子。
```

**分析类**：
```
请分析[内容]，从以下几个角度：[角度1]、[角度2]、[角度3]。
```

**编程类**：
```
请用[语言]写一个[功能]的代码，要求：[具体要求]。
```

## 常见问题解答

### Q：AI会泄露我的隐私吗？

A：正规AI产品都有隐私保护措施，但建议：
- 不要输入敏感个人信息（身份证、密码等）
- 不要输入公司机密信息
- 使用前阅读隐私政策

### Q：AI的回答准确吗？

A：AI可能出错，建议：
- 重要信息要核实
- 专业领域咨询专家
- 对AI回答保持批判性思维

### Q：免费版和付费版有什么区别？

A：一般区别：
- 付费版模型更强
- 付费版响应更快
- 付费版有更多功能
- 新手建议先用免费版

### Q：手机端和电脑端哪个好用？

A：
- 手机端：方便随时使用，适合简单对话
- 电脑端：适合长文本、复杂任务、文件处理
