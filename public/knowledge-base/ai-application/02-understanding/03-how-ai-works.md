# 第6章 AI是怎么工作的？

> 用简单的方式理解AI原理，从训练到推理，从数据到智能

## AI的"学习"过程

### 通俗比喻

> AI的学习就像小孩子学说话：
> 
> 1. **听**：听大人说话（读取大量文本）
> 2. **模仿**：尝试模仿说话（预测下一个词）
> 3. **纠正**：大人纠正错误（调整模型参数）
> 4. **熟练**：越说越流利（模型训练完成）

### 两个核心阶段

| 阶段 | 名称 | 做什么 | 比喻 |
|------|------|--------|------|
| 第一阶段 | 训练 | 学习知识 | 上学读书 |
| 第二阶段 | 推理 | 应用知识 | 工作干活 |

## 训练阶段：AI如何"学习"

### 第一步：收集数据

**做什么**：收集海量文本、图片等数据

**数据来源**：
- 📚 书籍、文章
- 🌐 网页内容
- 💬 对话记录
- 📝 代码库

**数据量级**：
- GPT-3训练数据：约5000亿词
- 相当于读了几百万本书

### 第二步：预训练

**做什么**：让AI学习"预测下一个词"

**简单例子**：
```
输入："今天天气真"
AI预测："好"（概率最高）

输入："床前明月"
AI预测："光"（概率最高）
```

**原理**：
- AI不是死记硬背
- 而是学习语言的"规律"
- 知道什么词后面通常接什么词

**比喻**：
> 就像你读到"白日依山"，脑子里自然想到"尽"一样。
> 
> AI也是这样，通过大量阅读，学会了语言的规律。

### 第三步：微调

**做什么**：让AI学会"好好说话"

**预训练的问题**：
- AI只会预测下一个词
- 不知道怎么和人对话
- 可能说一些不合适的话

**微调的作用**：
- 教AI如何回答问题
- 教AI什么该说、什么不该说
- 让AI更"懂事"

**方法**：
1. 人类写好问答示例
2. AI学习这些示例
3. 人类给AI的回答打分
4. AI根据反馈调整

### 第四步：对齐（RLHF）

**做什么**：让AI的价值观和人类对齐

**RLHF全称**：Reinforcement Learning from Human Feedback
（基于人类反馈的强化学习）

**过程**：
1. AI生成多个回答
2. 人类给这些回答排序
3. AI学习人类的偏好
4. 逐渐生成更符合人类期望的回答

**比喻**：
> 就像训练小狗：
> - 做对了 → 给奖励
> - 做错了 → 纠正
> - 慢慢就知道该怎么做了

## 推理阶段：AI如何"回答"

### 第一步：理解输入

**做什么**：把你的话转换成AI能理解的格式

**过程**：
```
你的话："今天天气怎么样？"
    ↓
分词：["今天", "天气", "怎么样", "？"]
    ↓
编码：[1234, 5678, 9012, 3456]（数字表示）
```

### 第二步：计算预测

**做什么**：预测下一个最可能的词

**过程**：
```
输入：["今天", "天气", "怎么样", "？"]
    ↓
AI计算：每个可能的下一个词的概率
    ↓
结果：{"好": 0.3, "不错": 0.25, "很好": 0.2, ...}
```

### 第三步：生成回答

**做什么**：选择概率最高的词，继续生成

**过程**：
```
第1步：今天天气怎么样？ → 好
第2步：今天天气怎么样？好 → ，
第3步：今天天气怎么样？好， → 阳
第4步：今天天气怎么样？好，阳 → 光
...
最终：今天天气怎么样？好，阳光明媚。
```

**关键点**：
- AI是一个词一个词生成的
- 每次都预测下一个最可能的词
- 所以AI回答有时会"卡顿"（在计算）

## 为什么AI能"理解"？

### 理解的本质

**AI的"理解"**：
- 不是真正理解含义
- 而是找到了词语之间的"关系"

**比喻**：
> AI就像一个从没见过苹果的人，但读了大量关于苹果的描述。
> 
> 它知道"苹果"和"红色"、"水果"、"甜"经常一起出现，
> 
> 所以能正确回答关于苹果的问题，但它从没真正"见过"苹果。

### Embedding的作用

**什么是Embedding**：
- 把每个词变成一串数字
- 意思相近的词，数字相似

**例子**：
```
"苹果" → [0.8, 0.3, 0.1, ...]
"水果" → [0.7, 0.4, 0.2, ...]  （和"苹果"接近）
"汽车" → [0.1, 0.9, 0.8, ...]  （和"苹果"远离）
```

**作用**：
- AI通过数字计算理解词语关系
- 不需要真正"理解"含义

## AI的局限性

### 1. 没有真正的理解

**问题**：AI只是在"模仿"，不是真正理解

**例子**：
```
问：把大象放进冰箱需要几步？
AI答：三步——打开冰箱、放进去、关上冰箱。

问：把长颈鹿放进冰箱需要几步？
AI可能答：四步——打开冰箱、把大象拿出来、放长颈鹿进去、关上冰箱。
（这是在"模仿"笑话的逻辑，不是真正理解）
```

### 2. 可能产生幻觉

**问题**：AI可能"一本正经地胡说八道"

**原因**：
- AI只是在预测下一个词
- 不保证事实正确
- 有时"编造"听起来合理的内容

**解决方法**：
- 重要信息要核实
- 使用RAG让AI查资料
- 让AI标注信息来源

### 3. 知识有时效性

**问题**：AI的知识有"截止日期"

**原因**：
- 模型训练有时间点
- 训练后发生的事情不知道

**解决方法**：
- 使用联网搜索功能
- 告诉AI最新的信息

### 4. 缺乏常识

**问题**：AI可能缺乏人类的基本常识

**例子**：
```
问：我昨天把手机放进冰箱了，现在怎么办？
AI可能答：拿出来，检查是否损坏...
（但人类会先问：你为什么把手机放冰箱？）
```

## 2026年的新进展

### 1. 从"预测下一个词"到"预测下一个状态"

**传统方式**：预测下一个词
**新方式**：预测物理世界的下一个状态（NSP）

**意义**：
- AI开始理解物理世界
- 为具身智能、机器人奠定基础

### 2. 从"单次对话"到"持续学习"

**传统方式**：每次对话独立
**新方式**：AI能记住历史，持续学习

**意义**：
- 更个性化的服务
- 更连贯的对话体验

### 3. 从"被动回答"到"主动执行"

**传统方式**：问什么答什么
**新方式**：AI主动规划、执行任务

**意义**：
- Agent智能体成为主流
- AI成为真正的"助手"
