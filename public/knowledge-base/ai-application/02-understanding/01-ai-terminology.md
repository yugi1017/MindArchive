# 第4章 AI名词解释（通俗版）

> LLM、Agent、MCP、RAG、Token等术语，用生活化比喻让你秒懂

## 为什么要懂这些名词？

当你开始接触AI，会遇到很多专业术语。不懂这些词，就像听天书一样。本章用最通俗的比喻，帮你把这些"生词"变成"熟词"。

## 核心名词速查表

| 名词 | 英文全称 | 一句话解释 |
|------|----------|------------|
| LLM | Large Language Model | 超级能聊天的AI大脑 |
| Agent | AI Agent | 能自己干活的AI员工 |
| Skills | AI Skills | AI的"专业技能包" |
| MCP | Model Context Protocol | AI连接外部工具的"翻译器" |

| Fine-tuning | - | 给AI做专业培训 |
| Embedding | - | 把文字变成数字坐标 |
| Hallucination | - | AI一本正经地胡说八道 |

## 详细解释

### LLM（大语言模型）

**正式定义**：Large Language Model，大型语言模型

**通俗比喻**：
> LLM就像一个读过全世界图书馆所有书的"超级学霸"。你问什么，它都能根据读过的内容给你回答。

**生活例子**：
- GPT-5.2、Claude 4.6、豆包2.0、DeepSeek V4 都是LLM
- 它们能对话、写作、翻译、编程，因为"读"过太多内容了

**为什么叫"大"**：
- 参数量大：相当于"脑细胞"特别多
- 数据量大：读过的内容特别多
- 能力强：能处理复杂任务

---

### Agent（智能体）

**正式定义**：AI Agent，能自主感知、决策、执行任务的AI系统

**通俗比喻**：
> 如果LLM是"大脑"，那Agent就是"大脑+手脚"。
> 
> 普通AI只能回答问题，Agent能自己动手干活。

**生活例子**：
- 你说"帮我订一张去上海的机票"
- 普通AI：告诉你怎么订
- Agent：直接帮你打开App、选择航班、完成预订

**2026年的Agent能做什么**：
- 🎯 理解目标
- 📋 分解任务
- 🔧 调用工具
- ✅ 执行闭环

---

### Skills（技能）

**正式定义**：AI Skills，预定义的专业能力模块，让AI具备特定领域的专业技能

**通俗比喻**：
> Skills就像给AI装的"专业技能包"。
> 
> 就像游戏角色可以学习不同技能，AI通过Skills获得专业能力。

**生活例子**：
- 文档生成Skill：AI学会写技术文档、周报、论文
- 代码审查Skill：AI学会检查代码质量、发现Bug
- 数据分析Skill：AI学会处理Excel、生成图表、写分析报告
- 翻译Skill：AI学会专业领域的翻译

**Skills vs MCP vs Agent的关系**：
```
┌─────────────────────────────────────┐
│           Agent（大脑）              │
│         决策、规划、协调              │
├─────────────────────────────────────┤
│          Skills（能力）              │
│         专业技能、工作流程            │
├─────────────────────────────────────┤
│           MCP（连接）                │
│     连接外部工具、数据、服务          │
└─────────────────────────────────────┘
```

**为什么Skills重要**：
- 🎯 让非开发者也能用AI：产品、设计、测试等岗位有专用Skills
- ⚡ 开箱即用：不需要每次都写复杂Prompt
- 🔄 可复用：一次配置，多次使用
- 📈 持续进化：Skills可以不断优化升级

**2026年热门Skills**：
| Skills类型 | 适用人群 | 功能 |
|-----------|---------|------|
| 技术文档生成 | 开发者 | 自动生成API文档、README |
| PRD撰写 | 产品经理 | 辅助写产品需求文档 |
| UI设计辅助 | 设计师 | 生成设计规范、组件描述 |
| 测试用例生成 | 测试工程师 | 自动生成测试用例 |
| 知识库收集 | 所有人 | 收集整理学习笔记 |

### MCP（模型上下文协议）

**正式定义**：Model Context Protocol，模型上下文协议

**通俗比喻**：
> MCP就像一个"万能翻译器"。
> 
> AI只会说"AI语言"，各种软件有自己的"软件语言"，MCP帮它们互相沟通。

**生活例子**：
- AI想读取你的日历 → 通过MCP连接日历App
- AI想发送邮件 → 通过MCP连接邮箱
- AI想查数据库 → 通过MCP连接数据库

**三层架构**：
```
┌─────────────────────────────────────┐
│           Agent（大脑）              │
│         决策、规划、协调              │
├─────────────────────────────────────┤
│          Skills（能力）              │
│         专业技能、工作流程            │
├─────────────────────────────────────┤
│           MCP（连接）                │
│     连接外部工具、数据、服务          │
└─────────────────────────────────────┘
```

---

### RAG（检索增强生成）

**正式定义**：Retrieval-Augmented Generation，检索增强生成

**通俗比喻**：
> RAG就是让AI"开卷考试"。
> 
> 闭卷考试：AI只能凭记忆回答（可能记错）
> 开卷考试：AI先查资料，再回答（更准确）

**生活例子**：
- 你问AI："公司去年的销售额是多少？"
- 没有RAG：AI可能瞎编一个数字
- 有RAG：AI先查公司数据库，再告诉你准确数字

**应用场景**：
- 企业知识库问答
- 法律文档查询
- 医疗诊断辅助

---

### Token（词元）

**正式定义**：AI处理文本的最小单位

**通俗比喻**：
> Token就像AI世界的"字"。
> 
> 但不完全等于我们说的"字"，有时一个词是一个Token，有时一个字是多个Token。

**生活例子**：
- 英文："hello" 可能是1个Token
- 中文："你好" 可能是2个Token
- 中文："人工智能" 可能是3-4个Token

**为什么重要**：
- AI按Token计费：用得越多，花钱越多
- AI有Token限制：一次能处理的内容有限
- 2026年主流模型支持128K-1M Token上下文

---

### Prompt（提示词）

**正式定义**：用户输入给AI的指令或问题

**通俗比喻**：
> Prompt就是你跟AI说的话。
> 
> 说得好，AI回答得就好；说得不好，AI可能答非所问。

**好Prompt的公式**：
```
背景 + 任务 + 要求 = 好结果
```

**例子**：
```
差Prompt：帮我写个周报

好Prompt：
背景：我是一名前端开发工程师
任务：帮我写一份本周工作周报
要求：
1. 本周完成了用户登录功能开发
2. 修复了3个Bug
3. 参加了2次技术评审会议
4. 格式要正式，200字左右
```

---

### Context（上下文）

**正式定义**：AI在一次对话中能记住和参考的内容

**通俗比喻**：
> Context就像AI的"短期记忆"。
> 
> 你跟它说过的话，它能在一定范围内记住。

**生活例子**：
```
你：我叫小明
AI：好的，小明，有什么可以帮你的？

你：我叫什么名字？
AI：你叫小明。（因为它记住了上下文）
```

**Context限制**：
- 每个模型有Context上限
- 超出限制，AI会"忘记"之前的内容
- 2026年主流模型支持超长Context

---

### Fine-tuning（微调）

**正式定义**：在预训练模型基础上，用特定数据进一步训练

**通俗比喻**：
> Fine-tuning就像给AI做"专业培训"。
> 
> 通用的AI是"大学生"，微调后变成"专业人士"。

**生活例子**：
- 通用AI：什么都知道一点
- 医疗微调AI：医学知识特别专业
- 法律微调AI：法律条文特别熟悉

**什么时候需要**：
- 需要AI在特定领域更专业
- 需要AI按特定风格回答
- 需要AI学习企业内部知识

---

### Embedding（嵌入）

**正式定义**：将文本转换为数值向量表示

**通俗比喻**：
> Embedding就是给每个词一个"坐标"。
> 
> 意思相近的词，坐标距离就近；意思不同的词，坐标距离就远。

**生活例子**：
- "苹果"和"水果"坐标很近
- "苹果"和"汽车"坐标很远
- AI通过坐标理解词语之间的关系

**应用场景**：
- 搜索：找到意思相近的内容
- 推荐：推荐相似的内容
- RAG：检索相关文档

---

### Hallucination（幻觉）

**正式定义**：AI生成虚假或错误信息，但表现得像真的一样

**通俗比喻**：
> Hallucination就是AI"一本正经地胡说八道"。
> 
> 它说得头头是道，但内容可能是编的。

**生活例子**：
```
你：李白写过《静夜思》吗？
AI（正确）：《静夜思》是李白的名作...

你：李白写过《代码之美》吗？
AI（幻觉）：《代码之美》是李白在唐代创作的...（完全是编的）
```

**如何避免**：
- 重要信息要核实
- 使用RAG让AI查资料
- 让AI标注信息来源

---

## 2026年新热词

### A2A（Agent-to-Agent）

**解释**：智能体之间的协作协议

**比喻**：AI员工之间的"工作群聊"

**应用**：多个Agent协同完成复杂任务

### 物理AI（Physical AI）

**解释**：能理解物理世界规律的AI

**比喻**：AI从"纸上谈兵"变成"知行合一"

**应用**：机器人、自动驾驶

### NSP（Next-State Prediction）

**解释**：预测世界的下一个状态

**比喻**：AI不只是预测下一个词，而是预测物理世界的下一步

**意义**：AI从数字空间走向物理世界
