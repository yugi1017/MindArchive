## 一、AI应用全景

### 1.1 为什么非开发人员也需要AI

AI正在改变所有岗位的工作方式：

| 岗位 | AI带来的改变 |
|------|--------------|
| **产品经理** | 从"写文档"到"设计产品"，AI帮你写PRD、做竞品分析 |
| **UI设计师** | 从"画图"到"创意指导"，AI帮你生成设计、出原型 |
| **测试工程师** | 从"写用例"到"质量把控"，AI帮你生成测试、找Bug |

## 三、产品经理的AI应用

### 3.1 AI能帮产品经理做什么

| 场景 | AI应用 | 效率提升 |
|------|--------|----------|
| 需求文档 | AI生成PRD、需求分析 | 50-70% |
| 竞品分析 | AI收集信息、生成报告 | 60-80% |
| 用户研究 | AI分析反馈、提取洞察 | 40-60% |
| 原型设计 | AI生成原型、交互设计 | 50-70% |
| 项目管理 | AI生成计划、跟踪进度 | 30-50% |

### 3.2 产品经理必备AI工具

#### 需求文档类

**Kimi K2.5 / 豆包 / 通义千问**
- 用途：生成PRD、需求分析、文档撰写
- 特点：中文优化好，长文档处理强
- 使用方式：网页版直接使用

**Prompt示例**：
```markdown
请帮我写一份用户登录功能的PRD文档，包含：
1. 功能概述
2. 用户故事
3. 功能需求
4. 非功能需求
5. 验收标准
```

#### 原型设计类

**UXbot**
- 用途：AI原型设计、高保真原型生成
- 特点：中文场景优化，一次性生成完整项目
- 核心功能：
  - 自然语言生成多页面原型
  - 可视化PRD文档
  - 前端代码一键生成

**使用示例**：
```
输入："设计一个电商APP首页，包含搜索栏、轮播图、商品推荐、底部导航"
输出：完整的高保真原型 + 交互演示
```

**Figma AI**
- 用途：UI设计、设计稿生成
- 特点：专业设计工具，AI辅助设计
- 核心功能：
  - AI生成设计稿
  - 自动布局建议
  - 设计系统管理

**即时设计**
- 用途：国产UI设计工具
- 特点：中文友好，团队协作
- 核心功能：
  - AI生成设计
  - 多人协作
  - 设计资源库

#### 竞品分析类

**Kimi / DeepSeek / 通义千问**
- 用途：竞品信息收集、分析报告
- 特点：推理能力强，分析深度好，联网搜索

**Prompt示例**：
```markdown
请帮我分析以下竞品：
1. 产品A：[产品名称]
2. 产品B：[产品名称]

分析维度：
- 核心功能对比
- 用户群体差异
- 商业模式分析
- 优劣势总结
```

### 3.3 产品经理AI工作流

```
需求收集 → AI整理分析 → 生成PRD → AI生成原型 → 评审迭代
    ↓           ↓           ↓           ↓           ↓
  用户反馈    竞品分析    文档撰写    原型设计    持续优化
```

### 3.4 实战案例

**案例：新产品需求文档**

```markdown
第一步：收集需求（使用Kimi）
"请帮我整理以下用户反馈，提取核心需求：
[用户反馈内容]"

第二步：生成PRD（使用豆包）
"基于以上需求，请生成一份完整的PRD文档"

第三步：生成原型（使用UXbot）
"根据这份PRD，生成产品原型"

第四步：迭代优化
"请帮我优化这个功能的交互流程"
```

## 八、AI使用技巧

### 8.1 通用技巧

**技巧一：角色设定**
```markdown
"你是一个资深产品经理，请帮我..."
"你是一个UI设计专家，请帮我..."
"你是一个测试工程师，请帮我..."
```

**技巧二：提供上下文**
```markdown
"背景：我们正在开发一个电商APP
目标用户：25-35岁都市白领
核心功能：商品浏览、购物车、支付
请帮我..."
```

**技巧三：迭代优化**
```markdown
第一轮：生成初稿
第二轮："请优化第2点，使其更具体"
第三轮："请补充遗漏的场景"
```
