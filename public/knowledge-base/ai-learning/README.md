# AI 学习知识库

> 让每个人都能掌握AI，用AI改变工作和生活

## 📖 知识库简介

本知识库旨在帮助初学者全面了解和掌握AI技术，特别是如何使用AI进行编程和日常工作。无论你是完全的AI新手，还是希望提升AI使用效率的开发者，都能在这里找到适合自己的学习内容。

### 核心目标

- **认识AI**：了解当前主流的大语言模型及其特点
- **掌握工具**：学会使用各类AI编程工具提升开发效率
- **理解概念**：掌握AI领域的核心术语和概念
- **实践应用**：将AI融入日常工作流程

## 🎯 如何开始学习

### 零基础入门者

1. 从 [大语言模型概述](./01-foundation/01-llm-overview.md) 开始，了解什么是大模型
2. 阅读 [AI名词解释](./01-foundation/02-ai-terminology.md)，建立基础概念
3. 选择一款 [AI编程工具](./02-tools/01-coding-tools.md) 开始实践

### 有一定基础的开发者

1. 直接查看 [工具对比选型](./02-tools/03-tools-comparison.md)，找到适合自己的工具
2. 学习 [AI工作流实践](./03-practice/01-ai-workflow.md)，提升工作效率
3. 参考 [学习路径规划](./03-practice/02-learning-path.md)，系统提升AI能力

### 希望快速上手的用户

1. 查看 [工具速查表](./appendix/tools-quick-ref.md)，快速了解各工具特点
2. 选择一个工具开始使用，边用边学
3. 遇到概念问题时查阅 [AI名词解释](./01-foundation/02-ai-terminology.md)

## 💡 学习建议

### 学习原则

1. **实践优先**：AI技术更新快，边用边学效果最好
2. **工具为辅**：AI是工具，核心还是解决实际问题
3. **持续更新**：保持对新技术的好奇心和学习热情

### 常见误区

| 误区 | 正确认识 |
|------|----------|
| AI能解决所有问题 | AI是辅助工具，需要人类判断和验证 |
| 必须学会所有工具 | 选择1-2个适合自己的工具深入使用 |
| AI会取代程序员 | AI提升效率，让程序员专注于更有价值的工作 |
