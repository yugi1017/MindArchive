# 大语言模型概述

> 了解AI的"大脑"，选择适合自己的大模型

## 一、什么是大语言模型（LLM）

### 1.1 基本概念

大语言模型（Large Language Model，简称LLM）是一种基于深度学习的人工智能模型，通过分析海量文本数据学习人类语言的规律，能够理解和生成自然语言。

**形象比喻**：

把LLM想象成一个"超级学霸"——它读完了互联网上几乎所有的书籍、文章、代码，学会了语言的规律和知识。当你问它问题时，它能基于学过的内容，预测并生成合理的回答。

### 1.2 工作原理

LLM的核心是一个"接龙游戏"：

```
输入："今天天气很好，我们决定去"
模型思考：根据上下文，最可能接什么词？
输出选项：公园(60%) + 爬山(25%) + 购物(10%) + ...
最终输出："公园"
```

模型通过数学计算，预测下一个最可能出现的词语，逐字生成回答。

## 六、大模型使用入门

### 6.1 基本使用方式

1. **网页版对话**：直接在浏览器中使用，最简单
2. **API调用**：通过编程接口调用，适合开发集成
3. **本地部署**：下载开源模型本地运行，隐私性好

### 6.2 提示词（Prompt）基础

好的提示词能获得更好的回答：

```markdown
❌ 差的提示词：
"写个函数"

✅ 好的提示词：
"请用Python写一个函数，实现以下功能：
1. 输入：一个整数列表
2. 输出：列表中所有偶数的和
3. 要求：包含错误处理和注释"
```

### 6.3 常见使用技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 角色设定 | 让AI扮演特定角色 | "你是一个资深Python开发者..." |
| 分步提问 | 复杂任务拆解 | 先问思路，再问实现 |
| 提供示例 | 给出期望格式 | "按以下格式输出：..." |
| 迭代优化 | 多轮对话完善 | "请修改第3点..." |
