## 学习指南

### 前置知识要求

在开始学习Spring Boot之前，建议具备以下基础：

| 知识领域 | 要求程度 | 说明 |
|---------|---------|------|
| Java基础 | 熟练 | Java 8+特性（Lambda、Stream、Optional） |
| Maven/Gradle | 了解 | 依赖管理、项目构建 |
| Spring Framework | 基础 | IoC、AOP基本概念 |
| 数据库基础 | 了解 | SQL语法、关系型数据库概念 |
| Web开发基础 | 了解 | HTTP协议、REST概念 |

## 第一阶段：入门篇

> **学习目标**: 掌握Spring Boot核心概念，能够独立搭建并运行Spring Boot项目

### 学习路径

```
第1章 架构概述 → 第2章 快速入门 → 第3章 配置体系 → 第4章 自动配置
```

### 章节内容

| 章节 | 标题 | 核心内容 | 学习目标 |
|------|------|----------|----------|
| 第1章 | [架构概述与设计哲学](./01-foundation/01-architecture-overview.md) | Spring生态演进、约定优于配置、自动配置机制 | 理解Spring Boot设计理念 |
| 第2章 | [快速入门](./01-foundation/02-startup-process.md) | 项目创建、启动流程、第一个REST API | 学会创建并运行项目 |
| 第3章 | [配置体系](./01-foundation/03-configuration-system.md) | 配置文件、属性绑定、多环境配置 | 掌握配置管理方法 |
| 第4章 | [自动配置原理](./01-foundation/04-auto-configuration.md) | 条件注解、自定义Starter、配置覆盖 | 理解自动配置机制 |

### 入门篇学习检验

完成入门篇后，你应该能够回答以下问题：

1. **概念理解**: Spring Boot的"约定优于配置"体现在哪些方面？
2. **实践应用**: 如何创建一个Spring Boot项目并实现简单的REST API？
3. **配置管理**: application.yml和application.properties有什么区别？如何实现多环境配置？
4. **原理理解**: @SpringBootApplication注解包含哪些核心注解？各自的作用是什么？

## 第二阶段：进阶篇

> **学习目标**: 深入理解Spring Boot核心原理，掌握IoC、AOP、Web开发、数据访问等核心技术

### 学习路径

```
第5章 IoC容器 → 第6章 AOP → 第7章 MVC → 第8章 RESTful → 第9章 事务 → 第10章 JPA → 第11章 Security
```

### 章节内容

| 章节 | 标题 | 核心内容 | 学习目标 |
|------|------|----------|----------|
| 第5章 | [IoC容器架构设计](./02-core/01-ioc-container.md) | 容器层次、BeanDefinition、生命周期、依赖注入 | 理解IoC容器架构 |
| 第6章 | [AOP面向切面编程](./02-core/02-aop-architecture.md) | 切面、切入点、通知、代理机制 | 掌握切面编程 |
| 第7章 | [Spring MVC架构原理](./03-web/01-spring-mvc.md) | DispatcherServlet、HandlerMapping、拦截器 | 理解MVC架构 |
| 第8章 | [RESTful API设计](./03-web/02-restful-api.md) | 资源设计、HTTP语义、版本控制、HATEOAS | 掌握API设计 |
| 第9章 | [事务管理机制](./04-data/01-transaction-management.md) | ACID、隔离级别、传播行为、声明式事务 | 理解事务管理 |
| 第10章 | [Spring Data JPA](./04-data/02-spring-data-jpa.md) | 实体映射、关联关系、Repository、性能优化 | 掌握数据访问 |
| 第11章 | [Spring Security架构](./05-security/01-spring-security.md) | 认证授权、JWT、CSRF、方法级安全 | 理解安全架构 |

### 进阶篇学习检验

完成进阶篇后，你应该能够回答以下问题：

1. **IoC原理**: Bean的生命周期包含哪些阶段？BeanPostProcessor的作用是什么？
2. **AOP应用**: 如何使用AOP实现日志记录？JDK动态代理和CGLIB代理有什么区别？
3. **Web开发**: Spring MVC的请求处理流程是怎样的？如何实现全局异常处理？
4. **数据访问**: 事务的传播行为有哪些？如何解决N+1查询问题？
5. **安全架构**: Spring Security的认证流程是怎样的？如何集成JWT？

> **学习目标**: 具备微服务架构设计能力，掌握生产环境部署与运维技能

### 章节内容

| 章节 | 标题 | 核心内容 | 学习目标 |

| 第12章 | [微服务架构设计](./07-microservice/01-microservice-design.md) | 服务拆分、服务通信、服务发现、API网关、分布式事务 | 理解微服务架构 |

### 实战篇学习检验

完成实战篇后，你应该能够回答以下问题：

1. **架构设计**: 微服务拆分的原则有哪些？如何确定服务的边界？
2. **服务通信**: 同步通信和异步通信各有什么优缺点？如何选择？
3. **分布式事务**: 常见的分布式事务解决方案有哪些？各自的适用场景是什么？

## 学习建议

### 学习方法

1. **理论先行**: 先理解概念和原理，再进行实践
2. **动手实践**: 每章内容配合代码示例进行实践
3. **问题导向**: 带着问题学习，完成章节后的思考题
4. **总结复盘**: 定期回顾，建立知识体系

### 复习机制

```
┌─────────────────────────────────────────────────────────────────┐
│                        复习周期建议                              │
├─────────────────────────────────────────────────────────────────┤
│  每日：使用附录速查表回顾关键知识点                              │
│  每周：复习本周学习内容，完成思考题                              │
│  每月：选择一个模块进行深度复习                                  │
│  实践：开发中遇到问题先查附录，再回溯学习                        │
└─────────────────────────────────────────────────────────────────┘
```
